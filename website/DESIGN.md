# 产品依据与设计系统

## 产品调研

设计前核对了仓库中英文 README、`assets/logo.svg`、`docs/branding.zh-CN.md`、最新 `docs/images/0.13.2/` 截图，代理与线路保护、工作区身份、资源预算、安全模型、快速入门、退出文档和 CHANGELOG，并阅读 Qt 样式、工作区页面和 Engine 收尾代码。下载指向 2026-11-12 核实的真实 `v0.13.2-windows` Release。

| 产品事实 | 网站表达与约束 |
| --- | --- |
| Windows 控制端，Linux 容器运行工具 | 定位为 Windows AI 编程隔离工作台，不描述成 Windows 虚拟机 |
| 选择项目并显式授权挂载 | 区分只读、读写与宿主信任；只读仍可读取共享文件 |
| 身份分开保存账号与浏览器资料 | 默认共享兼容旧版；切换项目不自动切换身份 |
| Chromium 与 CLI 隔离 | 浏览器不挂载项目和工具账号卷，沙箱失败不降级 |
| 固定线路与一个落地 | SOCKS5、HTTP、HTTPS 在同一个落地节点里表示替代选项，不串成三跳 |
| 第一跳和最终出口独立核验 | Windows 控制连线与工作区流量分开表示；兼容模式的外部分流边界另行说明 |
| 资源预算与监测分开 | 正常/低资源、按需浏览器、单独停止；不虚构实测提升比例 |
| 当前用户 DPAPI | 只描述应用代理配置和内部令牌保护，不宣称加密所有账号与 Profile 卷 |
| 容器仍依赖宿主与内核 | 不使用“绝对安全”“完全匿名”“无法识别”或独立审计等保证 |
| PolyForm Noncommercial | 明示非商业源码许可，不用 OSI 开源或免费商业授权描述 |

8. FAQ、版本记录与 Footer。

在 1920px、100% 缩放的普通 DPI 桌面，四张软件截图按原始逻辑宽度展示，避免额外缩字。普通 DPI 展示区保持截图正视，只用一个软件窗口和柔和阴影，不叠加窗口状背板；高 DPI 保留轻微静态透视，阅读模式保持正视。按展示空间捕获原生窗口，减少软件文字的缩小幅度；原始像素保留供放大阅读。阴影、背景与提示属于网页展示层，截图内部内容不修改。所有静态字体、图标和产品图片由本站提供，不依赖第三方运行时图片服务。

## 交互与可访问性

使用语义化分区、单一 H1、跳转到正文、可见键盘焦点、系统字体回退、移动导航和原生 dialog。网络模式支持方向键/Home/End，截图支持 Escape、上一张/下一张、滚动阅读与原图链接；FAQ 使用原生 details。无 JavaScript 时，预渲染的正文和实际下载链接仍可使用。
