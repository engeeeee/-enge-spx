# Project origin and attribution

ENGE SPX is a separately maintained personal project by engeeeee. Its initial
codebase continues the Windows implementation previously developed for
engeeeee/egress-workbench-app, released as the Windows 0.1 and 0.2 previews.

That implementation was informed by the public usage documentation and static
interface/configuration analysis of Egress Workbench by MOYU. The reference
project is https://github.com/bbfp/egress-workbench-app; its original documents,
images and releases are attributed to MOYU, copyright MOYU, under the licensing
terms published there.

ENGE SPX does not bundle the original macOS executable, protected application
modules, DMG or offline image archive. The earlier upstream screenshots, logo,
and macOS product documentation are not included in this new project. ENGE SPX
uses a new vector mark and documentation written for its Windows implementation.

The existing PolyForm Noncommercial License 1.0.0 text is retained as LICENSE.
This restructuring does not claim a new commercial grant or erase pre-existing
rights. Third-party component licenses and notices remain applicable and are
listed in THIRD_PARTY_NOTICES.md and in their installed distributions.

Some previous runtime names, recipe hashes and protocol identifiers are retained
solely to let existing installations keep their project containers, credentials
and browser data. Fresh installations use the ENGE SPX identity.

Independent repository hosting, a new Git history and a new brand describe
maintenance and distribution. They are not claims that every dependency or
historical design idea was authored from scratch by engeeeee. No affiliation or
endorsement by MOYU, Anthropic, OpenAI, Google or Docker is claimed.
