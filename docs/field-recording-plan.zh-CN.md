# 实机资源记录：审计与增量方案

基线 0.11.0，`fdd319a`。原计划中的身份与网络检查已交付，本批补充真实设备、真实用户任务的可复核采样机制；不将 CI 合成活动冒充实机测试。

## 已有实现与缺口

- `resource_monitor.Monitor` 已提供进程、所属容器、宿主和 Docker Desktop/WSL2 的只读计数，复用它，不新增监控服务或依赖。
- Qt 的资源页只在可见时采样，并用 `resource_inflight` 避免重叠；真正退出会取消并等待采样。记录复用同一采样通道，保持这些退出保证。
- 当前缺少跨一段真实使用时间的有界记录及脱敏导出，单点采样与短时 CI 不能定位持续增长或用户任务的资源表现。
- 现有网络报告已脱敏；资源原始信息含 PID、容器名称和项目 hash，不能直接写入可分享的记录。

## 文件顺序与风险

| 文件 | 方案 | 风险 / 复杂度 |
| --- | --- | --- |
| `resource_recording.py` | 版本化报告、字段白名单、逐报告标识代号、采样统计、时间/条数/体积上限、用户取消、可恢复中间文件与最终原子保存 | 中 / 中；未知或失败不作零占用，不保留路径、命令行、账号或任意异常正文 |
| `__main__.py` | `resources --record` 前台记录，显式时长、间隔和用户活动标签，Ctrl+C 保存已收集结果 | 中 / 低；不启动 Desktop，不调用 ready、不续租、不改变网络 |
| `ui/controller.py` | 用户主动记录，复用独占采样通道；首次采样在途时排队；隐藏可继续，真正退出取消并等待保存；数据迁移前收尾 | 高 / 中；避免第一次点击失败、线程重叠和退出后继续写文件 |
| `ui/window.py` | 在现有资源页设置时长/活动并选择输出文件；开始、停止保存、再次导出；无新增导航或自动启动 | 中 / 低；工作区操作可继续，不把手选活动标签当作软件已验证的 AI 活动 |
| 测试、CI、文档 | 覆盖脱敏、计数不可用、限额、取消/退出/迁移与并发、原生 OS 和 Docker，沿用原安全门禁 | 高 / 中；不得为记录关闭 guard 或放宽沙箱 |

默认不记录。窗口 X 仍隐藏托盘，真正退出默认停止工作区；主动记录会随真正退出结束并保存。语言/时区、代理后端、镜像配方和配置格式不变，原数据无需迁移。只向用户明确选择的文件输出记录；不上传报告。
