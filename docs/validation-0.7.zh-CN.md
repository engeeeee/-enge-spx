窗口适配代码使用 Win32 非客户区消息和窗口样式，不使用透明背景色去模拟边框。普通窗口、自定义标题栏和可缩放边缘保持一致；最大化时将可见客户区限制在对应显示器工作区。Windows 使用中文 UI 字体，文件及文件夹选择继续使用系统对话框。

早期检查发现最大化顶部 8 像素隐藏边距，以及首次布局重新加入旧边框尺寸的问题；已修正并完整重跑最终构建。被替代的构建在发布前取消，没有用它们生成公开的 0.7.0 资产。

1922 ms 是该 CI runner 的窗口首次显示耗时，不包含 Docker 初始化、运行环境下载或连接核验，不代表所有电脑都具有相同速度。

## 容器与已有功能

本次没有修改容器配方。最终构建仍执行了实际 Linux x64 容器集成：双来源出口核对、直接 TCP 出网阻断、浏览器和 OAuth 回调、网关租约到期、停止与重检后的项目和账号数据保留、数据迁移，以及本机前置和软件内加密双跳链路检查。

第一跳出口不符、线路失效、线路出口变化及污染的 `NO_PROXY` 不会使检测改走直连；线路诊断入口不提供跳过落地的工作区路径。导出的完整运行环境在 containerd 和 classic 两种存储中完成安装、重复安装及原有标签与数据保留检查。

## 尚未覆盖的范围

Windows CI 的窗口状态、原生消息和截图验证，不能替代用户实机上的完整拖动操作、多显示器切换、不同 DPI、Windows Snap 菜单，以及终端、Docker Desktop、v2ray 和真实节点的组合验收。当前包未代码签名，也未经过独立安全审计。

文件读写共享、工具账号共享、Chromium `--no-sandbox`、凭据存储和代理监测周期等边界继续存在，详见 [安全模型](security-model.zh-CN.md)。本次界面重构没有扩大这些隔离保证。
