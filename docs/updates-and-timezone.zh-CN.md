# 自动时区与软件更新

从 0.15.0 起，在 **偏好设置** 中管理这两项功能。

## 跟随最终落地出口的时区

默认选择 **跟随落地出口（自动）**。旧版本没有模式字段的配置也会使用自动模式，原固定时区保留为 `manual_timezone`；选择 **手动固定** 会恢复该值。保存设置，然后重新检查并确认连接。

1. 原有双来源检查先确认最终出口 IP，前置线路仍独立核验。
2. 地理请求通过同一受控代理查询这个明确的 IP，读取有效 IANA 时区；不使用前置线路地区，也不按国家推测时区。
3. 出口确认界面显示应用的时区，确认前再次核对出口和时区。无法识别时区时不会静默沿用洛杉矶，需重试或显式选择手动模式。
4. 新打开的 Claude/Codex/Linux CLI 使用所选 `TZ`，项目的 `/etc/timezone`、`/etc/localtime` 同步更新。浏览器使用原来的离线时区镜像机制，保持只读、UID1000、沙箱和 Profile。

已有项目容器的 ID、可写层、目录授权和账号卷保留。Docker 容器原始创建配置的默认 `TZ` 不能原地修改；应用启动 CLI 时显式提供新值，诊断分别列出这两个环境。直接在应用之外执行不带环境参数的 `docker exec` 仍可能读到旧默认值。网络控制容器只与工具共享网络命名空间，其文件系统另列，不作为 CLI 系统文件的证据。

已运行的旧 CLI 不热修改时区。重新检查会先停止当前工作区；保存工作后重新打开工具即可。Windows 本机时区、语言和字体保持用户自己的设置。IANA 规则处理夏令时，GeoIP 是近似数据，不提供匿名保证。

## 软件内更新

**0.14.x 尚无更新器，需要先手动安装一次 0.15.0。以后可在软件内更新。**

- 默认启动后检查官方正式版，每天最多一次；“检查更新”可立即重新检查。可取消“启动时自动检查更新”并保存。
- 发现新版后，导航中的“偏好设置”显示“有更新”。点击 **下载更新并重启…**，保存工作并确认后开始下载；支持已有下载缓存与续传。
- 校验完成后正常停止本实例工作区和后台服务，等待当前 GUI 完整退出，再由独立助手替换程序。更新不关闭 Docker Desktop，重新打开后仍由你启动环境。
- 安装版调用同目录当前用户安装器，保留快捷方式和卸载信息。便携版只替换发布包中的程序文件，额外文件、项目和数据目录保留。数据／项目与程序内部目录冲突时拒绝覆盖。
- 目录不可写、包不完整、校验不一致、文件被其它进程占用时不宣称成功。便携交换失败尝试还原旧文件；安装器失败保留完整旧程序快照并尝试恢复。恢复失败时保留备份，使用官方安装包修复。

更新使用“连接与代理”中的本机下载代理设置；要求代理时不会自动改为直连，不需要启动 Docker。检查与下载在工作线程执行，不记录账号、剪贴板或提示词。只使用固定官方仓库及正式标签；预览版、降级、不完整资产、超限 ZIP、路径穿越、NTFS 流及链接均不安装。

更新包放在数据目录 `updates` 下，跟随原有数据迁移位置。完整更新后会清理旧暂存缓存；程序目录保留一个 `._spx-rollback-*` 旧版备份，下一次成功更新时尝试清理更早的同实例备份。不要在这些自动管理的目录中保存项目。权限或占用妨碍清理时保留文件，不强删。

GitHub 的 SHA-256 与校验文件用于检查来源一致性和下载完整性；目前没有独立代码签名，不能对抗官方发布账户被攻陷。

## 终端玻璃与配色修复

0.15.0 只在实际进入原生移动／缩放循环时暂停 Acrylic；结束、取消或单击标题栏后按当前 GUI 线程状态恢复。短时检查仅在交互暂停期间运行，空闲无新增轮询。工具标签、边框及窗口按钮悬停色跟随暖灰／紫晶／石墨切换，原外观偏好继续保存。

## 实现与验证

| 文件 | 职责 |
| --- | --- |
| `exit_timezone.py`、`engine.py`、`state.py` | 时区模式、最终出口选择、确认复核和兼容字段 |
| `resources/checks/exit_probe.py`、`network_diagnostics.py` | 明确 IP 的受控 GeoIP 请求、CLI／Docker 默认环境分别报告 |
| `app_updates.py` | 正式版检查、缓存、下载校验、安全解包、更新交接 |
| `update_apply.py` | 进程身份、等待退出、安装／便携交换、恢复、重新打开 |
| `ui/controller.py`、`ui/window.py` | 设置入口、进度、用户确认、正常停止后交接 |
| `smart_terminal.py`、`window_effects.py` | 玻璃恢复和标签颜色 |

自动化命令：

```bash
PYTHONPATH=src python -m unittest discover -s tests -p 'test_app_update*.py' -v
PYTHONPATH=src python -m unittest discover -s tests -p 'test_exit_timezone.py' -v
python tests/integration_app_update.py --bundle dist/ENGE-SPX-Windows-x64-0.15.0-Portable.zip --setup dist/ENGE-SPX-Windows-x64-0.15.0-Setup.exe --output update-e2e.json
python tests/integration_exit_timezone.py --runtime-report integration-results.json --output exit-timezone.json
python tools/probe_windows_terminal_window.py --output terminal-caption.json
```

冻结更新验收只操作一次性副本、临时数据和自己启动的进程；覆盖含空格／中文路径、便携交换、实际 Inno 安装与重新打开。Docker 时区测试在同一项目层切换洛杉矶／东京，另核对只读镜像，不使用真实账号。终端探针仅向自己创建的 Qt 窗口发送事件，不能代替每种实体 Windows 桌面和鼠标的人工体验。

本次使用经过源码范围校验的精简发布路径：保留新功能、安装包、真实工作区／guard／双跳及镜像导入验证；未重跑与本次无关的完整协议矩阵和资源基准，沿用 0.14.6 的记录。
