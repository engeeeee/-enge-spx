## 处理的问题

打开 ENGE SPX 只检测 Docker 状态，不启动 Desktop、容器或环境下载。
点击“一键准备环境”或“启动并检测”等明确的启动操作后才会准备环境。
升级时忽略旧版的自动启动选项，偏好设置改为说明手动启动行为。

确认连接后，后台监测会立即检查环境并占用操作锁。原来的工具启动采用
非等待加锁，而且终端打开后又调用浏览器入口，再次加锁、核对连接并
准备浏览器，可能使第一次点击提示“环境正在执行其他操作”。

现在工具和浏览器入口最多等待 30 秒获取操作锁，界面继续响应；拿到锁后
重新核对连接，一次准备浏览器、项目与工具命令。终端打开后复用本次
浏览器地址。仅等待加锁，不重试工具启动；超时仍提示占用，连接失败
仍拒绝打开工作区。

## 升级

先退出旧版窗口再更新，避免单实例机制唤起仍运行的旧界面。便携版需完整
解压并保留 `_internal`。已有匹配镜像、账号卷、配置与项目可继续使用，
无需为了这次更新删除 Docker 数据。

容器与代理的隔离边界继续见 [安全模型](security-model.zh-CN.md)，
