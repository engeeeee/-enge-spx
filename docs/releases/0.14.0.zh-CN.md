**ENGE SPX 0.14.0 正式版 · Smart Clipboard Paste**

- 在 ENGE SPX 智能终端的 Claude Code / Codex 原始输入区按 Ctrl+V，直接粘贴文字、Windows 截图、图片和普通文件。无需额外上传窗口、保存截图或输入路径；保留草稿及同一 CLI 会话，由用户按 Enter 发送。
- Windows 原生读取 Unicode、CF_HDROP、PNG、DIB/DIBV5；图片转为 CLI 原生视觉输入，普通文件保留原件并插入引用。图片适配目前限 Claude **2.1.319** / Codex **0.167.0**；未知版本拒绝未经验证的图片输入，普通文件引用仍可用。PDF/DOCX 的内容读取依赖实际 CLI 工具链。
- 通过现有项目挂载流式、原子导入；只读项目使用本项目容器的私有临时目录。增加哈希、大小/配额、路径和会话校验、活动缓存锁及过期清理，不扩大 Docker 挂载、权限或监听端口。
- GUI 的 AI 自动模式使用受控 Qt/ConPTY；显式 Windows Terminal、PowerShell 和自定义终端设置继续保留。**外部终端不接管图片/文件 Ctrl+V**，不使用全局键盘钩子、模拟按键或窗口标题定位。
- 保留双出口核验、无 DIRECT 回退、异常停止、独立 Profile、资源预算、用户数据及先前 Docker 退出/工具更新修复。镜像配方未变，可复用现有运行环境。

**升级及开启：**完整退出旧托盘程序，再安装新版或完整解压便携包，沿用原数据目录。在设置中选择“自动（AI 智能粘贴）”或“智能粘贴终端”，保存并打开 Claude/Codex。已有外部终端不能被热接管；已打开的智能终端每次粘贴复用当前会话。读写项目的 `.enge-spx-clipboard/` 建议加入项目忽略规则；只读项目的临时附件不应视为持久备份。

**验证边界：**Windows/Linux 自动化、原生 Win32 Clipboard/ConPTY、实际 Docker 文件隔离，以及两款真实 CLI 到合成 API 的双图视觉数据均已验证。合成 API 不是模型识图结果；真实 Windows + Docker Desktop + 已登录模型的识图、文档读取、IME与端到端性能仍待人工验收。完整 Kitty/OSC52 不在本批范围。安装包仍未代码签名。
