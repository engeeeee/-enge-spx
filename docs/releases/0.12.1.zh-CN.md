**可选同时关闭 Docker Desktop**

- 在“偏好设置 → 启动行为”勾选“真正退出时同时关闭 Docker Desktop”并保存，真正退出时先停止并核验工作区、结束性能记录，再正常关闭 Docker Desktop。
- 默认不启用；X 隐藏托盘和“保留工作区退出”不触发。托盘及设置页退出按钮反映已保存的选择。联合关闭会中断其它 Docker 容器，不执行全局 WSL 关闭，不删除镜像、账号或卷。
- 使用有界的官方管理接口并确认 stopped。权限不足、旧版本不支持、状态未知或超时会保留界面，允许重试或取消联合关闭。设置保存失败不会用旧的全局选择继续退出。
- 退出偏好独立保存，原代理、身份、资源预算、账号和镜像配方保持兼容；原有沙箱、DPAPI、双出口和异常停止机制保留。

**升级：** 停止旧工作区并真正退出，完整安装或解压新版并保留数据目录，无需删除已有镜像。Windows 包仍未签名，属于 Preview。自动化使用独立模拟管理进程，不替代真实 Windows/Docker Desktop/WSL2 的交互及长时验收。

见 [操作与失败恢复](https://github.com/engeeeee/ENGE-SPX/blob/v0.12.1-windows/docs/exit.zh-CN.md)和 [源码、实际测试与性能范围](https://github.com/engeeeee/ENGE-SPX/blob/v0.12.1-windows/docs/validation-desktop-exit.zh-CN.md)。
