**ENGE SPX 0.14.6 正式版 · 字体清晰度与窗口缩放优化**

- 改善终端拉伸及 125%／150% 等分数缩放下的字体发虚。行距、行位图边距和绘制起点按物理像素对齐；文字先在实际背景上绘制，再一次性拷贝，避免透明字形二次混合与位图重采样。
- DPI 或逻辑分辨率变化后重新计算字体度量、网格和字形缓存；同步更新尚未完成时，按新比例重绘上一张已提交的文字帧。保留上一版完整帧防闪烁及 150ms 恢复上限。
- 拉宽窗口时忽略末尾无样式空白，复用已有文字位图；背景透明度切换保留布局及有界缓存。画面缓冲保留少量余量，连续小幅缩放减少整张分配，大幅缩小时回收。
- 完整帧快照按行读取缓冲，减少重复属性访问。行缓存仍受 128 行／64MiB 限制，不为整个聊天记录保留图片。
- GUI 和命令行两个 Windows 入口都显式声明 PerMonitorV2／PerMonitor，保持普通用户启动。冻结程序自检检查实际 DPI 感知状态。

Windows 专项以 100%、125%、150%、175%、200% 五种进程缩放、六种窗口比例比较单次直接绘字参考图，覆盖 ASCII、中文、组合字符、emoji 和 ANSI 样式；另补查 16／24pt 大字号。该探针使用真实运行的 Qt 窗口和合成内容，不包含个人剪贴板或账号。

同机合成测量中，125% 下连续缩放加呈现的中位数／P95 从 7.426／10.233ms 变为 3.856／5.120ms；24 次小幅缩放的画面分配从 24 次变为 2 次。**这不是实体显示器帧率、整机资源占用或所有机器的性能保证。** Windows 10/11 实体多显示器切换、触控板和桌面材质观感仍需实机确认。

原有 Acrylic、颜色、字号、右键只粘贴、输入法、拖选复制、智能图片附件及会话保持逻辑继续使用。没有新增依赖、全局输入监听、网络端口、挂载或容器权限；代理和账号配置不迁移。保存工作并关闭旧终端，再用原数据目录重新打开新版即可，无需重新准备 Docker 环境。需要回滚时停止工作区并换回 0.14.5，偏好文件保持兼容。
