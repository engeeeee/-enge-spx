**ENGE SPX 0.14.3 正式版 · Windows 10 鼠标、输入法与长对话滚动修复**

- 智能终端通过 `docker exec -i` 连接同一项目容器内的 Linux PTY，避免 Windows 10 自带 ConPTY 丢弃原生鼠标模式。单击定位继续由 Codex 自己处理，不模拟方向键、不增加聊天输入框。
- 中文输入法预编辑使用独立背景、正确基线和候选框光标位置，支持格式和换行；取消后恢复原内容，确认后只提交一次文字，不自动发送。
- 修复拖选复制后，选择快照拦截滚轮、使长对话只能查看当前屏幕的问题。普通滚轮继续浏览 CLI 自己的完整对话，保留当前草稿；Shift+滚轮用于终端输出缓存。
- 右键只把文字、截图或文件放入草稿；Windows CRLF 和末尾回车统一成为粘贴内容中的换行，用户仍需自己按 Enter。没有新增自动发送操作。
- 网络检查分别显示进程 `TZ`、实际偏移、`/etc/localtime` 的 IANA 名称和偏移，并比较 TZif 内容。**本版只确认和报告时区不一致，没有统一现有容器的系统时区文件。** `date` 按 `TZ=America/Los_Angeles` 显示 PST，而镜像 localtime 仍为 UTC 的现象仍可能存在。

已用真实 Codex 0.169.0、镜像中的 Codex 0.167.0 / Claude Code 2.1.319，在同一 Qt 窗口验证输入法、定点编辑、两张原生图片和明确 Enter 后的视觉数据序列化；Codex 另验证末尾换行粘贴与 120 行历史。合成 API 不能证明真实模型理解图片，用户物理 Windows/输入法组合仍需实机确认。

每个智能终端增加一个容器内 Python 标准库 PTY 中继进程，传输缓冲区有界，不新增常驻服务、依赖、端口、挂载或容器权限；尚无物理 Windows 修改前后资源对比。外部终端和本机预览继续使用原路径，现有镜像不需重建，配置、账号、项目和数据不迁移。

先从托盘真正退出旧版并关闭旧智能终端，再安装或完整解压新版，使用原数据目录并重新打开工具。正在运行的旧终端不会热切换传输层。
