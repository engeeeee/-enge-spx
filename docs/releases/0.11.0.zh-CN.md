**第四批升级：独立工作区身份、项目授权与网络证据**

- 新增工作区身份：Claude Code/Codex 的 HOME、Chromium Profile 和下载按身份独立。新身份从空白开始，需自行登录；默认共享保留旧账号。切换先停止并核验本实例，切回复用原数据及项目可写层，不增加多套常驻虚拟机。
- 项目可明确授权只读或读写。独立身份未绑定项目时拒绝工具启动；只读要求递归生效，不支持时拒绝启动。启动前检查身份、卷、项目源路径和权限，阻止串用账号及过期终端附加。
- 新增“网络检查”和 `network-check`：分开记录主机、容器、实际浏览器、第一跳及最终出口；展示路由、DNS、有限 IPv4/IPv6/UDP 阻断探测、语言/时区及本地 WebRTC 行为。可导出字段白名单及逐报告地址代号处理后的 JSON。
- 诊断不自动启动 Docker/浏览器，不修改语言、时区或指纹，不增加宿主公开/调试端口。出口复核失败、证实直连或发现浏览器安全条件变化时停止并核验本实例；guard 保持持续运行。
- 保留资源模式、Reality/WS/gRPC/Hysteria2、固定链路、双出口、DPAPI 和 Chromium 沙箱。X 仍隐藏托盘，真正退出默认核验停止工作区。无新增生产依赖、容器权限或许可证变更。

**升级：** 先停止工作区并退出旧版，再完整安装或解压新版，保留原账户和数据目录。默认共享无需迁移登录；使用新身份时显式应用项目授权。schema=1 的身份配置带初始化标记及上次设置备份，配置丢失/损坏拒绝回退共享，支持显式恢复；降级前需明确恢复共享/读写。只读不隐藏项目里的密钥，身份数据卷不属于 DPAPI 加密范围。

此版本仍为未签名 Preview。超时不等于无泄漏，本地 WebRTC 观察不能证明所有公网 STUN/TURN 行为；GeoIP/语言/时区不提供匿名保证。物理 Windows/WSL2、真实 AI 账号任务及长期交互性能仍需实机验收。见[身份与回滚](https://github.com/engeeeee/ENGE-SPX/blob/v0.11.0-windows/docs/workspaces.zh-CN.md)、[诊断范围](https://github.com/engeeeee/ENGE-SPX/blob/v0.11.0-windows/docs/network-diagnostics.zh-CN.md)和[八项交付记录](https://github.com/engeeeee/ENGE-SPX/blob/v0.11.0-windows/docs/validation-workspaces.zh-CN.md)。
