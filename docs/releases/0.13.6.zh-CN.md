**ENGE SPX 0.13.6 正式版**

- 修复 Docker 使用默认 WSL2 配置、设置文件未显式写出开启字段时，退出被 `wsl2_configuration/not_confirmed` 拦住的问题。支持大小写、包装值、分组设置及已知安装/策略层；不修改 Docker 的设置。
- 默认配置只有配合当前用户 Docker 发行版的 Version=2 注册证据，以及完整进程、管道和 WSL 停止检查才能通过。最终收尾前重读设置/注册再复查进程/管道；不以默认值或断连单独证明停止。
- 损坏、缺失、权限不足、明确关闭或不同后端/策略冲突给出固定分类；显式拒绝立即返回，短暂文件读取/共享失败仍在原预算内重试。保留所有 Fail-Closed 与数据保护机制。
- 增加真实格式的稀疏设置、旧设置、策略覆盖、错误值和状态变化回归，以及 Windows 原生文件/测试注册表/进程/管道的完整 Engine.shutdown 检查。CI 的 WSL 输出仍为夹具，不冒充用户设备实测。
- 保留 0.13.5 已修复的 Codex / Claude 用户目录更新和终端停留，镜像、配置格式、账号/Profile、代理、资源预算及许可证不变，无需重建环境。

升级前结束托盘中的旧界面。旧版无法正常退出时，可在托盘“更多 → 保留工作区，仅退出界面…”明确结束旧界面，再完整安装或解压新版并沿用原数据目录。安装包仍未代码签名。
