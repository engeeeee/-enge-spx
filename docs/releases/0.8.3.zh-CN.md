**安全更新：浏览器沙箱与 Windows 凭据保护**

- Chromium 启用非 root 命名空间和 Seccomp-BPF 沙箱，实际核对 renderer 的内核证据；初始化失败时明确拒绝启动，不使用无沙箱回退，不增加 SYS_ADMIN 或容器特权。
- Windows 代理配置与内部授权描述使用当前用户 DPAPI 加密。旧节点 ID、选择项与设置保留，迁移先验证再原子替换，权限或解密失败不清空数据。
- 网关和浏览器通过 stdin 向 RAM 交接必要凭据，网关使用 sealed memfd，宿主仅挂载非敏感租约；第三方终端不接收内部令牌。
- VNC 改为浏览器私有 Unix socket，X11 增加独立授权，继续支持工具的 localhost 登录回调、显示重连和持久 Cookie/Local Storage。
- 新增代理删除、派生引用清理、显式旧格式回滚及认证头/分享链接脱敏。保留项目可写层、工具账号和浏览器资料卷，以及打开软件不自动启动 Docker 的行为。

**升级前先停止旧环境并退出旧窗口，继续使用原 Windows 账户和原数据目录。** 本次需要更新网关与浏览器镜像；软件会获取匹配的新运行时。工作镜像及项目数据不因这次升级而重建。

Windows/Linux 各发现 171 项测试，分别按平台跳过 4/10 项，无失败；真实 DPAPI、完整 renderer、登录回调、Cookie/Storage 保留、190 秒续期、双跳断线阻断、迁盘、两种镜像存储及 Windows 安装卸载均已验证。实际 Windows/Docker Desktop/WSL2 内核组合与真实云账号仍需实机验收。

本批优先安全，未声称提速。同一 Linux CI 主机的离线浏览器就绪中位数从 0.54 秒变为 2.11 秒，含新增沙箱证明；已有浏览器继续复用。Windows GUI 单次首帧受缓存影响，不作提速结论。

工具账号和浏览器 Profile 仍默认在项目间共享，数据卷不属于本批 DPAPI 加密范围。Linux 使用私有文件权限。此预览版未代码签名、未经过独立安全审计，不提供匿名或完全宿主机隔离保证。

Reality、WebSocket/gRPC、Hysteria2/QUIC 和新的代理适配层属于第二批，0.8.3 尚未新增这些协议。
