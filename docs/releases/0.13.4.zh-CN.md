**ENGE SPX 0.13.4 正式版**

- 处理 Docker 关闭期间管道先消失、后台进程/WSL 稍后退场的竞态：退出核验改为有界等待完整停止证据，而非只观察第一份过渡状态。
- 工作区退出失败弹窗可直接重试、返回或复制诊断信息，摘要包含实际运行版本与具体核验阶段；不需要用户查找日志或输入命令。
- 自动尝试保存脱敏退出报告到当前数据目录 `logs/exit-diagnostics.json`。最多 64 项检查，不含原始命令/错误输出、路径、发行版名称、节点凭据或 IP，不自动上传；保存失败不掩盖退出问题。
- 停止核验仍严格执行，未核实停止时保留界面；不将管道不存在或超时当作成功，不启动/强制关闭 Docker，不停止其它 WSL 发行版。
- 账号、代理、身份、预算、退出偏好、镜像和项目资料兼容；无运行配方、第三方依赖、终端行为、权限或许可证变更。

**验证边界：** 已在源码中复现并覆盖上述关闭竞态，但反馈设备的实际触发条件仍未确认。本次等待和诊断增强不能作为已覆盖所有 Docker Desktop / WSL 组合的保证；证据不足时，弹窗直接复制的诊断可继续用于定位。

升级前保存工作并真正退出旧版，安装或完整解压新版，保留原数据目录即可。回滚到 0.13.3 无需逆迁移，但不包含本次等待和诊断功能。安装包仍未代码签名。
