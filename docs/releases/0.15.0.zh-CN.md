**ENGE SPX 0.15.0 正式版 · 落地自动时区、软件内更新与玻璃修复**

- 默认跟随最终落地 IP 的 IANA 时区，出口检查和确认时复核；查询经过原受控代理，区分前置线路和最终落地。不识别时区时提示重试或选择手动，不猜测地区。
- 保留手动固定模式与原手动值；已有持久环境可停止后更换时区。新 CLI 的 `TZ` 与项目系统文件一致，只读浏览器同步时区，保留原项目层、身份和账号资料。Windows 主机时区保持原设置。
- 新增软件内更新：启动后每天最多检查一次正式版，可关闭；发现新版后在偏好设置下载、校验并重启更新。安装版和便携版均支持，先正常停止工作区，不关闭 Docker Desktop。
- 固定官方来源、GitHub SHA-256 和同版本校验文件，限制资产与解包路径；保留额外用户文件和旧程序备份，便携失败回滚，安装失败尝试恢复。未增加提权、第三方常驻服务、依赖、网络端口或容器权限。
- 修复单击标题栏后 Acrylic 停留在纯色的问题；仅在实际移动／缩放时暂停，结束、取消后恢复。工具标签和窗口按钮悬停色随暖灰、紫晶、石墨切换。

**0.14.x 用户先手动安装一次本版，后续即可使用软件内更新。** 保存工作并关闭旧终端，使用原数据目录升级，然后重新检查、核对出口与时区。无需重新准备 Docker 镜像。GeoIP 不准确时可手动指定 IANA 时区；直接从应用之外执行 `docker exec` 的原始默认环境，与应用启动的 CLI 环境分别报告。

本次按维护要求使用精简验证：新功能单元／UI、Windows 冻结安装／便携更新、标题栏事件、两次实际 Docker 时区、现有工作区／安全续期／双跳和归档导入。没有重跑未改动的完整协议矩阵和资源性能基准。实体用户桌面的鼠标与毛玻璃观感仍需实机反馈；当前包仍未代码签名。
