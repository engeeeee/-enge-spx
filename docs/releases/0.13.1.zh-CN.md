**ENGE SPX 0.13.1 正式版**

在 Windows 上统一管理 Claude Code、Codex 和工作区浏览器：工具运行在 Linux 容器中，可选择独立账号身份、授权项目只读或读写，并通过指定线路与落地代理访问服务。

- 保留 Chromium 沙箱、Windows DPAPI、固定代理链路、两级出口核验及异常停机。
- 支持现有主流代理协议、SOCKS5/HTTP/HTTPS 落地与本机 v2ray 兼容模式。
- 提供项目/容器资源预算、低资源模式、独立浏览器停止、资源记录、网络检查和按需测速。
- 打开软件由用户决定何时启动 Docker；X 隐藏到托盘，真正退出默认停止工作区，可选择同时正常关闭 Docker Desktop。
- 本次统一软件界面、EXE 元数据和 GitHub 正式版标识，发布为 Latest；功能与 0.13.0 保持一致，后续按实际使用反馈继续优化。

**升级：** 保存工作、停止工作区并真正退出旧版，再完整安装或解压新版，保留原数据目录。账号、代理、身份、资源预算和退出偏好继续使用；没有配置迁移、镜像配方或依赖变更。

Windows 包仍未代码签名，项目尚未经过独立安全审计；用户实际 Docker Desktop/WSL2、v2ray、终端和显示器组合的长时体验需持续验证。正式版标记不代表匿名、账号可用或性能保证。

见 [使用说明](https://github.com/engeeeee/ENGE-SPX/blob/v0.13.1-windows/README.md)、[隔离与安全边界](https://github.com/engeeeee/ENGE-SPX/blob/v0.13.1-windows/docs/security-model.zh-CN.md)及 [实际发布验证](https://github.com/engeeeee/ENGE-SPX/blob/main/docs/validation-0.13.1.zh-CN.md)。
