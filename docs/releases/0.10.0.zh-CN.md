**第三批升级：资源预算、占用来源与独立浏览器管理**

- 新增“资源与性能”：分别查看应用进程、本实例 Linux 容器、主机及可读取的 Docker Desktop/WSL2 计数；仅概览可见时按需采样，不自动启动 Docker。
- 提供正常、低资源和自定义模式，可设置各类容器及单个项目的 CPU/内存预算。正常默认保留旧上限；低资源默认不连带启动浏览器。保存变更先停止本实例，下次检查时应用，保留项目 ID/可写层、账号和浏览器资料；支持恢复上次设置。
- 浏览器可单独打开或停止，停止时释放对应显示服务，CLI、网关和 guard 保持运行。显式登录仍准备沙箱浏览器，不使用本机或无沙箱回退。
- 完善退出：X 隐藏托盘，真正退出（含 Ctrl+Q）默认停止本实例。任务先安全取消/完成，后台和资源采样收尾后核验停止；失败保留界面重试。明确保留工作区的选项放入“更多”并要求确认，不再混同普通退出。
- 减少后台 UI 刷新和重复设置写入，保留固定代理链路、双出口、30 秒网络复核、租约、异常停机、DPAPI 和托盘。
- 新增实际 cgroup、归属/失败/恢复、原生进程计数与句柄、采样生命周期、浏览器暂停/恢复和同机阶段测量；没有新增生产依赖或权限。

**升级：** 先停止旧工作区并退出界面，再完整安装/解压新版，使用原账户和数据目录。匹配镜像可复用，资源设置缺失时沿用旧默认，无需清空数据。低资源模式可能降低编译速度或导致内存不足，不保证提速；多项目预算会累加。Docker 不能用 memory=0 清除已有上限，仅恢复网关不限内存时替换无用户数据的网关，项目容器不因此重建。

此版本仍为未签名 Preview。物理 Windows/WSL2、真实 AI 服务任务及交互 noVNC 的长期性能不以合成夹具代替；多身份 Profile 属于下一批。详见[操作与回滚](https://github.com/engeeeee/ENGE-SPX/blob/v0.10.0-windows/docs/resources.zh-CN.md)和[八项交付、测试与性能范围](https://github.com/engeeeee/ENGE-SPX/blob/v0.10.0-windows/docs/validation-resources.zh-CN.md)。
