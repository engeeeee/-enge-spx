**ENGE SPX 0.13.5 正式版**

- 修复 Windows Docker 管理命令超时后，子插件仍持有输出管道、耗尽离线核验预算的问题。改用限量私有临时文件捕获，给完整离线核验保留最多 8 秒；仍需确认进程、引擎管道和 WSL 状态，不把断连或超时当作停止。
- 退出诊断区分查询超时、预算耗尽和平台不适用，便于定位真实失败阶段。工作区离线核验总预算为 20 秒，可选联合关闭保留原 60 秒时限；不强制关闭 Desktop / WSL。
- Codex / Claude 的 npm 更新使用当前身份的持久化 `~/.local` 前缀，修复普通用户无法写入镜像系统安装目录的问题。使用原有非 root 用户与受控网络，兼容已有镜像、容器、账号和 Profile，不新增共享身份目录。
- GUI 打开的 AI 工具或登录工具结束后显示退出码，并保留容器内 Shell，更新成功或失败均可查看结果、手动重启工具。普通 CLI 继续传递原退出码，自定义终端仍使用统一接口。
- 新增真实进程继承句柄、预算预留、工具参数/退出行为及真实 Docker 中的 Codex / Claude npm 安装、持久化和身份边界验证。最终结果见验证记录；模拟/测试自有进程不能替代用户设备的 Docker Desktop / WSL2 验收。

升级前先退出托盘中的旧界面，防止单实例机制继续唤回旧版。旧版无法正常退出时，可显式使用“更多 → 保留工作区，仅退出界面…”结束旧界面，然后完整安装/解压新版并沿用数据目录。安装包仍未代码签名。
