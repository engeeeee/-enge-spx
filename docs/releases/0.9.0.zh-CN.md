**第二批升级：主流代理协议、网络隔离与系统托盘**

- 新增 VLESS Reality/Vision、VLESS/Trojan/VMess 的 WebSocket 与 gRPC，以及 Hysteria2/QUIC（固定端口，可选 salamander）。复用已有 sing-box 1.14.3，不额外安装代理核心。
- 支持常见 Clash/Mihomo 节点和 HTTPS 订阅；只导入节点，不执行其 DIRECT、分组、自动回退、DNS 或外部 provider。参数错误定位到条目与字段，不回显凭据。
- Hysteria2 实际经过 QUIC/UDP，支持经过所选第一跳连接 SOCKS5/HTTP(S) 落地；UDP 不通、密钥/认证或证书错误不回退直连。不兼容的 TCP 前置组合提前拒绝。
- 内部网络升级为 isolated bridge，补足宿主服务边界。自动先停止、再迁移并恢复原地址；项目容器 ID、可写层、账号和浏览器资料保留。失败保持停止，支持中断续迁与元数据回滚。
- 关闭窗口隐藏到系统托盘；右键可显示主窗口、保留工作区退出界面，或停止工作区并退出。Docker Desktop 与其它软件容器不会被一同关闭。
- 保留 0.8.4 的旧浏览器自动修复、通用第三方终端，以及浏览器沙箱、Windows DPAPI、最小凭据交接、双出口确认与异常停机。没有新增生产依赖、额外宿主端口或权限放宽。

**升级：** 在旧版停止环境并退出界面，完整安装/解压新包，以原 Windows 账户打开原数据目录。首次重新检查会自动升级本实例内部网络并要求重新核对出口；无需清空数据。合格的旧运行镜像可复用。0.9.0 关闭窗口后仍驻留托盘，更新程序前请从托盘明确退出。

已增加实际 TLS/Reality/QUIC、UDP 分片/故障、固定链路、证书/认证错误、DNS/IPv6/宿主旁路、迁移中断恢复、旧 ID 兼容和托盘回归，并保留正式发布的 Windows/Linux、完整沙箱、凭据、长期续租、安装卸载与镜像导入门禁。详见[实际测试与边界](https://github.com/engeeeee/ENGE-SPX/blob/v0.9.0-windows/docs/validation-p1.zh-CN.md)。

不支持 XHTTP/KCP、gRPC multi-mode、插件、跳端口和其它未经验证的扩展。资源预算、多 Profile 和环境诊断属于后续批次；不宣称本批已完成。仍为未签名 Preview，不保证匿名、服务可用或公网速度。完整参数、升级与回滚见[使用说明](https://github.com/engeeeee/ENGE-SPX/blob/v0.9.0-windows/docs/proxy-p1.zh-CN.md)。
