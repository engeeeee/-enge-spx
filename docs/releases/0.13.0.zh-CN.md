**按需 HTTPS 速度测量与实机验收**

- 网络检查页新增“测试 HTTPS 速度”，CLI 新增 `network-test`：通过最终受控链路测量 HTTPS 首字节和单次下载速率，前后复核两级出口与拓扑。
- 固定访问 Cloudflare，最多三次测速请求、约 1 MiB 应用载荷；测量阶段 15 秒预算，出口复核另需时间/流量。不自动测速、上传报告、启动 Docker 或增加第一跳测速入口。
- 保留 TLS/名称验证；拒绝重定向、异常编码和超量响应，限制慢响应总时长。失败不直连或切换节点。证书/出口/拓扑异常请求并核验停止；会话变化丢弃旧结果，不停止替换后的环境。
- GUI/CLI 可导出本次脱敏计数报告，缺失不算零速度；真正退出等待测量收尾。保留 0.12.1 的可选关闭 Desktop、资源记录、身份隔离、沙箱和原网络保护。
- 增加 Windows/WSL2 六阶段资源与长时/休眠/断线/退出验收指南，明确真实设备与账号仍需实测。

**升级：** 停止旧工作区并真正退出，完整安装或解压新版并保留原数据目录。没有持久配置迁移、镜像配方或依赖更改，原镜像和账号可复用。Windows 包仍未签名，属于 Preview。

测速的首字节不是 RTT，小下载不代表线路上限、AI 请求速度或 noVNC 流畅度。见 [使用和限制](https://github.com/engeeeee/ENGE-SPX/blob/v0.13.0-windows/docs/network-measurement.zh-CN.md)、[实际验证](https://github.com/engeeeee/ENGE-SPX/blob/v0.13.0-windows/docs/validation-network-measurement.zh-CN.md)与 [Windows 验收](https://github.com/engeeeee/ENGE-SPX/blob/v0.13.0-windows/docs/windows-acceptance.zh-CN.md)。
