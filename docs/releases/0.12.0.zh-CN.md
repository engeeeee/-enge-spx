**实机性能记录与资源访问边界改进**

- 在“资源与性能”新增“实机记录”：手动选择时长、活动和输出位置，记录自己的 Claude/Codex、浏览器或空闲过程。默认不记录，复用原采样器，不增加常驻服务或容器。
- 应用、所属容器、宿主、Docker Desktop 与共享 WSL2 分开记录，PID/容器采用逐报告代号；不读取账号、路径、AI 输入、命令行或环境变量。缺失不算零占用，最高采样值不冒充完整峰值。
- 首次点击可等待当前采样/操作结束；记录时其它工作区操作可继续。X 隐藏托盘，已经开启的记录继续；真正退出取消并等待保存。数据迁移前自动收尾，保存失败保留中间文件和可再次导出的结果。
- CLI 新增 `resources --record`，带时长/间隔上限和 Ctrl+C 保存。最长一小时、最多 720 样本、最终报告 4 MiB；无自动上传。
- 资源查询与启动复用本机 IPC 核验，连接 daemon 前拒绝 SSH/TCP、远程命名管道和 Unix URI 主机部分。保留手动 Docker 启动、沙箱、DPAPI、固定出口、guard、身份隔离与原退出规则。

**升级：** 停止旧工作区并退出，再完整安装/解压新版，保留原数据目录和账户。没有配置迁移或镜像配方变更，原镜像、账号与身份可复用。仍为未签名 Preview；记录工具提供实机证据收集能力，不代表维护者已完成用户设备或真实 AI 账号的长期验收。
