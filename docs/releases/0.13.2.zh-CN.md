**ENGE SPX 0.13.2 正式版**

修复 Docker Desktop 与 ENGE SPX 的退出衔接：

- 联合关闭改用官方异步正常关闭请求，随后独立确认状态，减少同步等待造成的超时；短暂的管理接口断连会在原有时限内继续核验。
- 先手动关闭 Docker，再退出软件时，核实本机 Desktop 已停止后完成后台清理，无需重启 Docker。
- 工作区已停止而 Desktop 尚未确认关闭时，可重试、返回，或仅本次退出 ENGE SPX；保留已保存的联合关闭设置。
- 管道错误本身不算停止证据；继续撤销租约、清理运行时敏感引用并等待本实例服务收尾。X 隐藏到托盘、默认停止工作区的行为保留。

**升级：** 保存工作、停止工作区并真正退出旧版，再完整安装或解压新版，保留原数据目录。账号、代理、身份、预算、退出偏好及既有镜像继续使用，无配置迁移或重新下载运行环境的要求。需要回滚时停止工作区后换回 0.13.1，保留数据目录即可。

本次不调整终端启动逻辑；偶发的终端“拒绝访问”问题按维护者要求留待后续复现处理。不强制结束 Docker Desktop，不执行全局 WSL 关闭。包仍未代码签名，真实用户设备长时使用的情况继续按反馈验证。

见 [退出说明](https://github.com/engeeeee/ENGE-SPX/blob/v0.13.2-windows/docs/exit.zh-CN.md)与 [实际发布验证](https://github.com/engeeeee/ENGE-SPX/blob/main/docs/validation-0.13.2.zh-CN.md)。
