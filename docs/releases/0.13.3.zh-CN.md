**ENGE SPX 0.13.3 正式版**

修复先完全退出 Docker Desktop 和后台，再退出 ENGE SPX 时出现缺失命名管道、退出尚未完成的问题。

- 管理接口不可用时，改用独立的本机 WSL2 停止核验：精确 Desktop Linux context、明确的 WSL2 设置、完整后台进程列表、管道不存在和 Docker WSL 实例已停止必须同时成立，并在收尾后复查。
- 核实停止后，完成租约撤销、运行时敏感引用清理和本实例后台服务收尾，无需重新启动 Docker；可选联合退出也识别管理接口已经退出的情况。
- 引擎仍运行、权限不足或证据不完整仍保留界面，不把单次连接错误当成停止，不强制结束 Desktop，不停止其它 WSL 发行版。
- 保留现有账号、代理、项目身份、预算、退出偏好、镜像与数据；不调整终端启动、网络保护、浏览器沙箱、依赖或许可证。

保存工作并真正退出旧版后，安装或完整解压新版，保留原数据目录即可。无需配置迁移或重建运行环境；回滚到 0.13.2 也不改变数据格式，但会重新受到旧退出限制影响。包仍未代码签名。

见 [退出说明](https://github.com/engeeeee/ENGE-SPX/blob/v0.13.3-windows/docs/exit.zh-CN.md)与 [验证范围](https://github.com/engeeeee/ENGE-SPX/blob/main/docs/validation-0.13.3.zh-CN.md)。
