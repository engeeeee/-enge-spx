# Windows / WSL2 实机验收

本页是可重复执行的实机步骤，不是已完成验收的声明。自动化使用云端 Windows GUI 和真实 Linux Docker；真实 Windows/Docker Desktop/WSL2、v2rayN、终端、AI 账号与交互 noVNC 的组合仍须在对应设备验证。

使用已保存工作的测试项目，记录 Windows、Docker Desktop/Engine、WSL 后端、应用版本和终端类型。保持相同项目、身份、代理链路和浏览器任务进行前后比较；每次只改变一个选项。不要公开代理、订阅令牌、账号或包含浏览器访问令牌的完整链接。

## 六个资源阶段

在“资源与性能 → 实机记录”选择输出文件、活动标签与时长。活动是人工标签，不会读取 AI 输入或证明该工具正在运行。单份最长 60 分钟，可分段记录；这不是工作区挂机时长上限。

| 阶段 | 操作和证据 |
| --- | --- |
| 应用关闭时基线 | 用 Windows 任务管理器/资源监视器记录全机、Docker Desktop 和 vmmemWSL；注明 Desktop 是否已打开及其它 WSL 发行版/容器是否运行。观察工具自身也有开销 |
| GUI 空闲 | 打开 ENGE SPX 后不启动工作区，观察是否自动启动 Docker；记录 `gui_idle`。新安装和旧配置都应保持由用户手动启动 |
| 容器运行、工具空闲 | 确认连接后记录 `workspace_idle`，分别用正常和低资源模式；模式变更会停止工作区，需重新核对并启动 |
| Claude Code / Codex 活动 | 手动执行同一真实任务并记录 `claude` / `codex`；注明任务时长、结果、模型/网络条件，不在报告或 Issue 放入提示词和账号 |
| Chromium / noVNC 活动 | 记录 `browser`，完成网页加载、输入、滚动、显示重连；单独停止浏览器，验证 CLI 仍可用且 Profile 保留 |
| 工作区完全停止 | 记录 `stopped`，检查本实例容器与后台服务已停止，账号/项目保留，其他应用容器不受普通停止影响；Desktop/WSL 缓存不必归零 |

应用、容器、主机、Desktop/WSL 的内存不能简单相加。当前资源记录包含观察者成本，CLI 单独记录时控制进程计数指记录器自身，不代表未登记的 GUI。默认不记录；隐藏 GUI 后只有明确启动的记录继续运行。见 [记录说明](field-recording.zh-CN.md)。

## 稳定性和退出

| 场景 | 操作与预期观察 |
| --- | --- |
| 浏览器单独使用 | 不操作 shell，持续浏览并分段记录；确认不因 shell 空闲断开，guard 继续续期。CI 已测 190 秒，不等于本设备的多小时验收 |
| 最小化与 X | 测量/下载/工作区仍可在托盘运行；恢复同一窗口，输入和控件正常 |
| 真正退出 | Ctrl+Q 或托盘退出应完成当前非取消任务、工作区核验和记录保存，随后关闭界面。失败时保留窗口，不误报成功 |
| 可选联合退出 | 先测试默认保留 Desktop，再勾选“退出时关闭 Docker Desktop”并保存；真正退出才正常关闭 Desktop。这个明确选择会中断其他 Docker 任务，X 和保留工作区退出不触发 |
| 睡眠/唤醒与长暂停 | 观察时钟、租约和连接状态；若租约已过期，应停止或要求重新确认，不能自动沿用失效授权。本设备实际恢复行为需记录 |
| 线路/落地中断 | 分别断开线路与落地，记录发现、停止和恢复过程；异常应停止，无 DIRECT 回退。检测有周期、请求超时和租约边界，不承诺立即发现 |
| Docker 重启 | 保存工作后重启 Desktop，观察应用保持响应、旧连接不被当作有效，重新检查确认后再用；账号和项目保持 |
| 显示与终端 | 测试实际多显示器、125/150/200% 缩放、切换终端、中文输入输出与登录回调；不依赖特定第三方终端品牌 |

停止 ENGE SPX 工作区不等于关闭 Docker Desktop；关闭 Desktop 不等于压缩虚拟磁盘，也不保证其它 WSL 发行版缓存立即释放。不要用删除卷、prune、重置环境或全局 WSL 关闭代替验收。

## 网络对照

先运行“网络检查”保存对象明确的脱敏证据，再按需运行“测试 HTTPS 速度”。出口复核耗时、HTTPS 首字节、小响应速率、真实 AI 响应与 noVNC 体验分开记录。测试真实编程任务时同时记录是否存在其它下载/视频/编译；不能用单次测速为 CPU、显示或服务端排队下结论。

调整节点或预算后重新确认同一测试条件，每种条件重复采样并保留完整分布和失败样本，不只选最快结果。新功能的[请求范围](network-measurement.zh-CN.md)与 [CI 证据](validation-network-measurement.zh-CN.md)不代表物理设备已经通过。
