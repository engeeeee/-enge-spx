# 网络环境检查与脱敏报告

0.11.0 Preview 新增；当前公开版本及下载以 Releases 为准。检查由用户主动运行，不增加常驻网络任务或取代 guard。

0.13.0 在同页另提供[有界 HTTPS 速度测量](network-measurement.zh-CN.md)。普通检查不会自动测速；既有出口复核耗时不等于 RTT 或下载吞吐量。

## 使用

先检查并确认工作区连接，再打开“网络检查 → 检查网络环境”。检查当前已应用身份，不会启动 Docker 或已停止的浏览器；要检查实际浏览器，请先显式打开它。复核失败、发现成功直连或浏览器安全条件变化时，请求停止并核验本实例。

```powershell
spx network-check
spx network-check --skip-browser
spx network-check --output D:\Reports\spx-network.json
```

`checked` 表示本次请求的检查已完成，不是匿名或全球无泄漏保证。`partial` 表示部分信息不可用或浏览器未运行；`not_ready` 表示未启用工作区，未启动环境。`failed` / `unsafe` 会使 CLI 返回 2，报告同时记录停止是否经过核验。未能确认停止时不要理解为容器已全部关闭。

## 检测对象与证据

| 对象 | 读取或实测内容 | 能证明与不能证明 |
| --- | --- | --- |
| Windows 控制主机 | NoProfile PowerShell 的默认 IPv4/IPv6 路由及 DNS，用户区域语言（GetUserDefaultLocaleName）和当前时区偏移 | 只读，不主动连接公网；主机默认路由不能用于判断容器泄漏。区域语言不等于所有已安装 UI 语言；权限/组件不足时标明不可用 |
| Linux 控制主机 | `/proc/net/route`、`ipv6_route`、`resolv.conf` 等只读信息 | 与容器分开，不当作 Windows/WSL2 整体测量 |
| 受控 session | 实际路由、DNS 服务器、IPv6 接口、网络 namespace、LANG/LC_ALL、TZ/偏移；直连 IPv4/IPv6 TCP 与 UDP DNS 的有限探测 | TCP/UDP 成功即异常并停止；无响应或超时不能单独证明没有发包。拓扑审计和真实防泄漏集成测试为另外的证据 |
| CLI | 拓扑审计核对其共享的 session 网络空间、身份及授权 | 不读取账号文件、项目内容或运行中的工具输入；共享 namespace 不冒充独立进程逐包抓包 |
| 浏览器 | 当前实际 `navigator.language/languages`、请求语言、Intl 时区、偏移、WebRTC API/候选、受控容器回环 STUN 接收计数与策略文件 | 通过临时本地页面观察，不打开调试端口或修改指纹；没有验证所有公网 STUN/TURN 服务。策略文件与观察分开记录，不把文件存在等同于所有网络行为已验证 |
| 第一跳 | 独立线路出口复核和耗时 | 无前置线路时明确标为未配置，不套用最终落地结果 |
| 最终出口 | 两来源复核、与已确认出口的一致性、耗时及已有近似 GeoIP 信息 | 耗时包含多次 HTTPS 请求，不是网络 RTT、吞吐量或真实 AI 任务性能；GeoIP 不作安全判断 |

阻断探测使用容器内的固定公开目标：IPv4 TCP `1.1.1.1:443`、IPv6 TCP `[2606:4700:4700::1111]:443`、UDP DNS `1.1.1.1:53`，查询示例域名 `example.com`。DNS 配置为回环，由应用 HTTP 代理处理目标域名；一次系统解析成功可能来自本地服务或缓存，不能单独推导实际远端 DNS 路径。完整受控路径仍依赖网关配置和集成防泄漏测试。

第一跳和最终出口请求复用既有两个检测来源与保护逻辑；TLS/超时等只返回固定错误类别，不记录原始密码、URL 或异常正文。网关内部握手错误不一定能从工作容器准确区分具体协议原因，此时保留通用传输失败，不能将它假装成确定的 TLS 诊断。

## 时区与语言

报告比较浏览器与容器的实际时区偏移、主要语言，并展示出口近似时区的偏移差异。不同 IANA 名称可能具有相同当前偏移；同一国家也可能有多个时区。差异不等于泄漏，不会触发自动语言/时区伪装。

本批语言只读。镜像使用 en_US.UTF-8，终端仍能输入和输出中文；未增加中文字体。时区继续使用明确设置的 IANA 值，已经建立的持久环境保持固定；更换时区需采用独立数据目录及重新确认流程。不会修改 Windows 系统时区、语言、浏览器 UA、WebGL 或字体指纹。

0.14.3 补充系统时区文件证据：`name` / `offset_seconds` 来自进程 `TZ`，`localtime_name` / `localtime_offset_seconds` 来自 `/etc/localtime` 的真实 TZif；`localtime_matches_process_offset` 比较当前偏移，`localtime_matches_tzif` 比较所选 IANA 文件与系统文件内容。文件缺失、畸形或未知时为 `null` / `unavailable`。报告不导出文件内容或任意链接路径。当前设置只传入 TZ，镜像的系统 localtime 仍可能是 UTC，因此 `date` 显示 PST 而系统文件指向 UTC 的现象属实；本版诊断不修复该文件，也不把“浏览器偏移与进程相同”当作系统文件一致的证明。统一系统文件需要单独的只读镜像/现有容器迁移，不能靠 root exec 或放宽只读根目录处理。

## 导出与隐私

“导出脱敏报告”只导出已生成的结果，不重新检查。报告使用字段白名单，IP、网络前缀、mDNS、身份与容器标识以每份报告独立的代号表示；同一份内相同地址保持同一代号，跨报告不复用地址映射。回环及未指定地址保留，便于理解配置。

报告不包含项目路径、代理服务器/订阅 URL、密码、浏览器令牌、Cookie、Local Storage、原始 SDP 或账号文件内容。系统类型、语言、时区和近似地区仍是环境信息；脱敏不等于统计匿名化。分享前可再检查输出；它是一份带时间的快照，不能代替后续持续监测。

浏览器观察器只在容器内部回环地址临时监听，观察后关闭，不增加宿主监听端口、公开端口或持久调试服务；仅凭据经 Docker exec stdin 传入，不放在命令行参数中。
